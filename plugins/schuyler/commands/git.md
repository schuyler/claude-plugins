# Instructions on using Git

* Put Git worktrees in `${PROJECT_ROOT}/.worktree/`, which is assumed to be in the global `.gitignore`.
* If you are writing code, *never* use `git add -A` -- add files explicitly before committing.
* When writing commit messages or merge request message, keep it SUCCINCT as you are writing for an expert audience. Focus on the motivation for the change, what was changed, why we believe the change is correct, and how we tested it (if we tested it).
